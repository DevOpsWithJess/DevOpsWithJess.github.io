# Artifact Two: Algorithms and Data Structures

## CS 300 ABC University Course Planner

### Original Artifact

This artifact originated from CS 300 Data Structures and Algorithms. The original application loaded course data from a CSV file and allowed users to search for courses and view course information using a hash table data structure.

### Enhancement Summary

For my CS 499 enhancement, I expanded the functionality of the Course Planner by adding additional sorting and filtering capabilities. Users can now view courses by course number, course title, or course level. These enhancements improved usability while preserving the fast lookup performance provided by the original hash table design.

The project demonstrates the importance of selecting appropriate data structures based on application requirements. A hash table was retained for efficient course searches, while vectors were used when sorting operations were required. This approach balanced performance, flexibility, and maintainability while highlighting the tradeoffs involved in software design.
