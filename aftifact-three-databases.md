# Artifact Three: Databases

## CS 360 WeightTrack Lite Mobile Application

### Original Artifact

This artifact originated from CS 360 Mobile Architecture and Programming. The original WeightTrack Lite application allowed users to record and track weight loss progress through a mobile interface. User data was stored using SharedPreferences and basic application functionality focused on recording weight entries and displaying progress information.

### Enhancement Summary

For my CS 499 enhancement, I improved the database design and functionality of the application by migrating weight tracking data to SQLite and creating user-specific database relationships. This enhancement improved data integrity, scalability, and overall application organization by ensuring weight records remained associated with the correct user account.

Additional improvements included the implementation of a progress report feature that transforms stored weight data into meaningful information for users. The application now provides reporting metrics such as starting weight, current weight, goal weight, weight change, and progress toward goals. I also enhanced the reporting logic to use the most recent weight entry date rather than insertion order, improving the accuracy of user results.

These enhancements demonstrate the importance of database design, relational data management, data integrity, and transforming stored data into useful information for decision-making.
