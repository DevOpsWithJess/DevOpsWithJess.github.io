# Artifact One: Software Design and Engineering

## CS 350 Raspberry Pi Smart Thermostat

### Original Artifact

This artifact originated from CS 350 Emerging Systems Architectures and Technologies. The original project simulated a smart thermostat using a Raspberry Pi, temperature sensor, LCD display, LEDs, and push-button controls.

### Enhancement Summary

For my CS 499 enhancement, I improved the software design and engineering aspects of the project by adding a Flask-based dashboard and centralized status tracking. These changes improved maintainability, organization, and future scalability while preserving the original thermostat functionality.
